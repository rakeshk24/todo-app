# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Flask todo app. Primary purpose is to demo and test CodeRabbit auto code reviews on GitHub PRs. Development is intentionally incremental — small features added one PR at a time.

**Do not write perfectly clean code.** Leave minor issues (missing input validation, inconsistent error handling, small style violations) so CodeRabbit has real findings to surface in the review process. Do not add code comments explaining the intentional issues.

## Repository

- **Remote**: https://github.com/rakeshk24/todo-app.git
- **Main branch**: `main`

## Development Workflow

- Every change goes on a new branch and is pushed for a PR
- Branch naming: `feature/`, `fix/`, `chore/` prefixes (e.g. `feature/todo-search`)
- Commit messages: short, imperative, under ~5 words, no attribution (no "Generated by Claude" etc.)
- PRs are opened manually by the user after push

## Running the App

```bash
python3 app.py
```

Runs on **port 5001** (`http://localhost:5001`).

## Stack

- Python, Flask, Flask-SQLAlchemy
- SQLite database (`instance/todos.db`)
- Jinja2 templates in `templates/` (`index.html`, `edit.html`), CSS in `static/style.css`

## Storage

SQLite via Flask-SQLAlchemy. Schema lives in `app.py` as the `Todo` model. Keep schema changes additive to avoid data loss.

## Coding Standards

Defined in [CODING_GUIDELINES.md](./CODING_GUIDELINES.md). Key points:

- PEP 8, 4-space indent, max 100 chars per line
- `snake_case` for functions/variables, `PascalCase` for classes
- No bare `except` — catch specific exceptions
- Never interpolate user input into raw SQL — use ORM methods
- Never use `| safe` filter on user-controlled data in Jinja2
- Use `textContent` not `innerHTML` for untrusted DOM content
- No inline styles — CSS classes only
- Validate input server-side; use `flash()` for user-facing errors

## Dependencies

- Pin all versions in `requirements.txt`
- Do not add packages for problems stdlib can solve

## What Not to Commit

- `.env`, `*.db`, `__pycache__`, build artifacts
- Secrets or credentials of any kind
