# Contributing

## Development Setup

```bash
git clone https://github.com/rakeshk24/todo-app.git
cd todo-app
pip install -r requirements.txt
python3 app.py
```

The app runs on `http://localhost:5001`.

Set `ALLOW_INSECURE_HTTP=1` to skip HTTPS enforcement in development:

```bash
ALLOW_INSECURE_HTTP=1 python3 app.py
```

## Branching

Use prefixed branches:

| Prefix | Use |
|--------|-----|
| `feature/` | New functionality |
| `fix/` | Bug fixes |
| `chore/` | Tooling, deps, docs |

Branch name: kebab-case, e.g. `feature/todo-search`.

## Commit Style

Short, imperative messages (≤5 words):

```
add priority sort controls
fix deadline parsing edge case
update requirements pins
```

No "Generated by", no "WIP", no trailing punctuation.

## Running Tests

```bash
python3 -m pytest tests/ -v
```

Or via Make:

```bash
make test
```

## Linting

```bash
make lint
```

This runs `flake8` against `app.py`, `utils/`, and `config/` with `--max-line-length=100`.

## Seeding Data

```bash
make seed
```

Populates the local SQLite database with sample todos for development.
