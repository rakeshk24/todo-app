REST API

Example URL: https://your-domain.example/api/todos

Replace your-domain.example with your HTTPS host.

Pass your API key as the X-API-Key header.

Get one todo with GET /api/todos/<todo_id>. A missing todo returns status 404 with JSON {"error": "Todo not found"}.

curl https://your-domain.example/api/todos \
  -H "X-API-Key: <your-key>"
curl https://your-domain.example/api/todos/123 \
  -H "X-API-Key: <your-key>"
curl -X POST https://your-domain.example/api/todos \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{"title":"My todo","description":"Details"}'

Replace 123 with the todo ID.
